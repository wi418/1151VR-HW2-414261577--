# Unity 2D HW2 - 奶龍跳躍遊戲

## 專案介紹
本專案為 Unity 2D 課程作業，使用 2D 圖片作為遊戲角色，製作基本的角色移動與跳躍功能。

## 遊戲功能
- 角色左右移動
- 角色跳躍
- 支援空中連續跳躍
- 使用 Rigidbody2D 處理重力與物理效果
- 使用 Collider 進行地板碰撞

## 操作方式
- A / D 或方向鍵：左右移動
- Space：跳躍，可在空中再次跳躍

## 使用工具
- Unity 6
- C#
- Visual Studio

## 專案資料夾
- `Assets`：遊戲場景、角色圖片及程式
- `Packages`：Unity 套件設定
- `ProjectSettings`：專案設定

## 製作說明
本作業匯入自備的 2D 角色圖片，建立遊戲場景與地板，並透過 C# 腳本控制角色移動及跳躍。
